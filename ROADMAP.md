# Roadmap

This is a living document. It reflects the current best thinking on what to
build next, not a contract. It should change as homedash is used and learned
from.

## Shipped

Nothing yet.

## Up Next

1. **homedash v1** — ship the complete personal start page with both display
   modes over one shared data layer: weather, bookmarks, eBird year stats, and
   llmdash headroom. The mode choice sticks per device, the layout works on
   laptop and phone, and access remains private to the tailnet.

---

## On the Horizon

- Learn from daily use before adding more widgets or another presentation
  direction.
- Revisit richer bookmark management if v1's chosen storage approach proves
  too cumbersome.
- Consider deeper history or alerts for eBird, weather, or coding headroom only
  after the glanceable core earns its place as the daily start page.
